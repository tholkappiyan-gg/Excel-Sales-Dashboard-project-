Excel-Based Sales Performance and Profitability Analysis

Project Overview
This project focuses on analysing sales performance and profitability across different product categories, cities, sales channels, and regions using Microsoft Excel.

Objectives
- To analyse sales and profitability across product categories.
- To identify top-performing cities and regions.
- To evaluate sales performance across different sales channels.
- To compare regional sales and profit contributions.
- To develop an Excel dashboard for business insights.

Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard

Dataset Description
The dataset contains 1,000 sales records and 13 business-related columns, including customer segment, region, city, sales channel, sales representative, category, product, unit price, sales, total cost, profit, payment method, and order status.

Analysis Performed
1. Category-wise Profit Analysis
2. City-wise Sales and Profit Analysis
3. Sales Channel-wise Sales Analysis
4. Region-wise Sales and Profit Analysis
5. Category-wise Product Record Analysis

Key Insights
- Electronics generated the highest category-wise profit.
- Bengaluru recorded the highest city-wise sales.
- Kolkata recorded the highest city-wise profit.
- Online was the largest sales channel by sales.
- West recorded the highest regional sales.
- East recorded the highest regional profit.

Project File
Excel Workbook: India_Sales_Dashboard_Practice.xlsx

Conclusion
This project demonstrates the use of Microsoft Excel for analysing sales data, identifying business trends, and presenting meaningful insights through Pivot Tables, Pivot Charts, and a dashboard.
